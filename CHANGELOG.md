# История изменений (Changelog)

Все заметные изменения проекта фиксируются в этом файле.

## [1.1.0] - 2026-10-28
### Добавлено
- Полная русскоязычная локализация CLI-интерфейса и справочной информации.
- Новый пресет пиксель-арта: `skull` (Ретро-череп).
- Подробный раздел часто задаваемых вопросов (`FAQ.md`).
- Руководство для авторов новых шаблонов (`CONTRIBUTING.md`).

## [1.0.0] - 2026-10-28
### Первый релиз
- Движок рендеринга 7x52 ячеек календаря активности GitHub.
- 4 уровня градации интенсивности зеленого цвета.
- Генератор 7-строчного шрифта для любого произвольного текста.
- Быстрый буст активности на сегодня (`--today N`).
- Набор стартовых шаблонов: `invader`, `cat`, `heart`, `ghost`, `hi`.
- Юнит-тесты и автоматизированный GitHub Actions CI.
