# Руководство по участию в разработке (Contributing)

Мы рады любым предложениям и новым пиксель-арт шаблонам!

## Как предложить новый шаблон:
1. Создайте текстовый файл в папке `presets/<имя_шаблона>.txt`.
2. Высота шаблона должна составлять ровно 7 строк (дни с воскресенья по субботу).
3. Используйте цифры `0`, `1`, `2`, `3`, `4` или символы `.` и `#`.
4. Проверьте отображение локально:
   ```bash
   python painter.py --art <имя_шаблона> --preview
   ```
5. Запустите тесты:
   ```bash
   python -m unittest discover -s tests
   ```
6. Откройте Pull Request с кратким описанием шаблона!
