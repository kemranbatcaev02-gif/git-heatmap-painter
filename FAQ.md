# Часто задаваемые вопросы (FAQ)

### 1. Почему после пуша коммиты не отображаются на графике GitHub?
- **Проверьте email**: Убедитесь, что email, указанный в вашем локальном git (`git config user.email`), привязан к вашей учетной записи GitHub (*Settings -> Emails*).
- **Приватный репозиторий**: Если репозиторий приватный, включите опцию в настройках профиля: *Settings -> Profile -> Contributions -> "Include private contributions on my profile"*.
- **Кэширование GitHub**: Иногда GitHub обновляет график активности с задержкой от 2 до 10 минут.

### 2. Как удалить нарисованный арт, если я передумал?
- Просто удалите или переведите в статус архива репозиторий с коммитами на GitHub (*Settings -> Danger Zone -> Delete this repository*). Через несколько минут все коммиты из этого репозитория исчезнут с вашего графика активности.

### 3. Безопасно ли использовать утилиту?
- Да, на 100%. Скрипт генерирует коммиты в абсолютно изолированный репозиторий и никогда не затрагивает ваш рабочий код и существующие проекты.

### 4. Можно ли рисовать на прошедших годах?
- Да, используйте флаг `--year <ГОД>` (например, `--year 2024`), и скрипт сгенерирует коммиты с точными датами за выбранный календарный период.
